# ClayCraft Pottery Studio

> Ceramics and pottery website template for classes, commissions, and gallery drops.

## Live Demo

See it in action: [https://creatiquemedia.com/templates/claycraft-pottery-studio/demo](https://creatiquemedia.com/templates/claycraft-pottery-studio/demo)

## Who It Is For

Pottery studios, ceramic artists, kiln workshops, teaching collectives, and gallery-shop brands.

A studio-focused pottery template with class calendar, workshop enrollment, commission requests, and gallery and shop sections.

## What's Included

**Key sections and features:**

- Workshop and class enrollment calendar
- Commission request intake for custom pieces
- Studio process storytelling and artist bio sections
- Collection launches and gallery conversion flow

**Additional features:**

- Class enrollment flow for wheel, hand-building, and glazing workshops
- Commission intake with timeline and budget pre-qualification
- Drop-based collection launch pages
- Monthly workshop calendar for firing days and studio events
- Artist storytelling sections
- Gift card and membership options

**Demo page blocks:** Class Calendar, Kiln Queue View, Commission Intake.

## Design & Tech Highlights

Built with Next.js, React, TypeScript, and Tailwind CSS, with Stripe and PWA support listed in the template stack.

## Customization

Through the done-for-you white-label service, it can be tailored for wheel classes, hand-building workshops, or a hybrid gallery-shop model.
